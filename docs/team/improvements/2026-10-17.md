You asked for anything that would make the experiment produce better results, run faster, or improve in some related

## How it runs
1. **Scout:** three agents look for improvements, one per lens:
   - validity: can we trust the results?
   - speed: the critical path and slow feedback loops
   - loop leverage: the human and agent loop itself
   
   Every idea must cite evidence from the repo or a measurement.
2. **Rank:** a planner scores each idea as value × confidence / effort and groups them into waves. Within one wave, no
   two items write the same file. The result goes to `2026-10-17-plan.md`.
3. **Critique:** a reviewer tries to refute each wave-1 item, then corrects the plan.
4. **Execute:** the lead spawns one agent per wave-1 item. Each item lands with a check that shows it worked.
5. **Record:** each item gets an entry below with its outcome and numbers.
