Verdict: the A/B decision rule

Fw.Verdict.better_soundtheoremprovednot reviewed

When lower is better, a "better" verdict means every variant run was strictly lower than every control run.

Uses

C = control runs, V = variant runs (integers). Cases are tried top to bottom; |C| counts repeated values; a single tie between the two sides gives noise.

Lean statement
theorem better_sound {ctl var : List Int}
    (h : verdict .lower ctl var = .better) :
    ∀ y ∈ var, ∀ x ∈ ctl, y < x

Lease: one device, FIFO queue

Fw.Lease.step_invtheoremprovednot reviewed

Every command keeps the lease invariant: nobody waits for a free device, nobody is queued twice, and the holder is not also waiting.

Uses

A state is s = (h, Q): h is the holder's lease or ⊥ (free), so there is at most one holder by construction; Q is the FIFO queue of waiting owners.

Lean statement
theorem step_inv {s : State} (c : Cmd) (h : Inv s) : Inv (step s c).1
